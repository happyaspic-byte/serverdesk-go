# Security policy

Operational security architecture and hardening requirements are documented in
[`docs/SECURITY.md`](docs/SECURITY.md), with credential migration in
[`docs/CREDENTIALS.md`](docs/CREDENTIALS.md).

Report suspected vulnerabilities through this repository's private GitHub Security Advisory
channel. Include affected versions, reproduction steps, impact, and any proposed mitigation.
Do not place credentials, customer addresses, production logs, or exploit payloads in a public
issue. Maintainers should acknowledge a complete report within three business days and provide
a remediation/status update within ten business days.

Supported versions are the latest signed release and, during a documented upgrade window, the
immediately preceding minor release. Development snapshots are not supported production builds.
